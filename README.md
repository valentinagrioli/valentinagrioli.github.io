# Portfolio · Valentina Grioli

Sitio estático (HTML + CSS + JS, sin instalar nada). Se publica solo con GitHub Pages.

## Estructura
- `index.html` → el home.
- `casos/` → una página por caso (`elite-industrial.html`, `tukimedia.html`, …).
- `css/styles.css` → colores, tipografías y animaciones (los colores están arriba de todo como variables).
- `js/main.js` → animaciones (título del hero, aparición al scrollear, collage que sigue el mouse).
- `img/` → imágenes exportadas del Figma.

## Cómo cambiar algo
- **Un texto:** abrí `index.html` en GitHub, tocá el lápiz ✏️, cambiá el texto y "Commit changes". En 1 o 2 minutos se actualiza la web.
- **Una imagen:** subí la nueva a `img/` con el mismo nombre (Add file → Upload files).
- **Un caso nuevo:** copiá `casos/elite-industrial.html`, cambiale el nombre y el contenido, y linkealo desde el botón "Ver proyecto completo" del home.
